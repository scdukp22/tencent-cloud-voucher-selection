## 从领券到下单，顺序别搞反

正确顺序是：先确认账号身份和要买的东西，算清订单金额，再领券，最后下单。倒过来做，很容易出现券领了用不上、或者券快过期了才匆忙下单的情况。

1. **确认身份**。个人实名只能领 1675 元包，企业实名和个人都能领 3780 元包。企业账号不要盯着 38 元秒杀，那是个人专享。
2. **算订单金额**。打算买什么、正价多少、能不能凑到目标门槛。差一点点到门槛的话，加一块云硬盘或延长一年时长通常比放弃这档券划算。
3. **领券**。在领券中心领取，注意 30 天有效期。
4. **下单时勾选**。结算页会列出当前订单可用的券，系统按门槛自动匹配，不需要输入任何兑换码。一单只能勾一张。
5. **核对是否属于活动价**。如果结算页根本勾不到券，基本就是这笔订单走的是活动价，回到第 2 步重新算。

**一张订单能用几张券？** 一张。想多用只能拆单，且每笔都要各自达到门槛。

**1675 元券包是不是能省 1675 元？** 不是。那是四张券面额相加，一笔订单只能用一张，实际节省看你的订单金额落在哪一档。
